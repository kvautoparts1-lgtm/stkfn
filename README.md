# StonkFun Scanner Bot

Automated bot designed for Railway deployment that continuously scans StonkFun public tokens for:
- Claimable creator fees > $46 USD
- Holder count <= 2

## Deployment on Railway
1. Unzip this directory or upload the code to a GitHub repository.
2. Connect your repository to Railway as a new Node.js project.
3. Railway will automatically install dependencies and run `npm start`.
